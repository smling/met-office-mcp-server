# Memory Bank

This directory stores durable project context for future agents and contributors.
Read these files before making changes, and update them whenever work changes project behavior, architecture, dependencies, configuration, or known risks.

## Files

- `project-context.md`: Current project purpose, stack, entry points, and runtime assumptions.
- `decisions.md`: Durable implementation decisions and the reason behind them.
- `progress.md`: Recent completed work, verification status, and follow-up notes.
